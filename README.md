# Grizs.github.io

Simple static site for the Grizs Roblox restaurant.

How to edit:
- Open `index.html` to change text, menu, and structure.
- Add images into the `images/` folder and then update the `images` array in `script.js` with the filenames (for example `images/restaurant-1.jpg`).
- Change the "Join on ROBLOX" link by editing the `join-button` href in `script.js` or directly in `index.html`.

Deploy to GitHub Pages:
1. Go to repository Settings > Pages.
2. Choose branch `main` and folder `/ (root)`, then Save.

If you want a contact form that actually sends messages, use a service like Formspree and set the form `action` to the Formspree URL.
